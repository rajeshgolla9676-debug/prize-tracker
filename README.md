# PriceTrack

A responsive price-tracking dashboard built with plain HTML, CSS and JavaScript.

## Demo login

- Username: `kiran`
- Password: `123`

## Features

- Login screen and session handling
- Dashboard overview
- Tracked product cards
- Add/delete products
- Search and sorting
- Target price tracking
- Price-drop calculations
- Price history table
- 7/30 day visual overview chart
- Demo price refresh
- LocalStorage persistence
- Responsive mobile layout

## Run

Open `index.html` in a browser. No build step or backend is required.

> Note: this is a front-end demo. The login credentials and product data are stored client-side and are not suitable for production authentication.
